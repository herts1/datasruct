## 一、题目要求分析

### 1.1 问题描述

通讯公司提供优惠通话套餐服务。给定大量手机用户通话记录（每条记录含拨出方和接收方的11位手机号码），要求根据手机号码或姓名快速查询通话次数最多的"聊天狂人"。

### 1.2 功能需求

| 功能 | 描述 |
|------|------|
| **哈希表构建** | 以手机号码和姓名为关键字，分别建立两个哈希表（约30人） |
| **查找聊天狂人** | 查找并显示通话次数最多的用户（号码、姓名、次数） |
| **按姓名查询** | 显示某用户的通话记录、身份证号、手机号；不存在输出 `No Info` |
| **哈希函数比较** | 至少2种哈希函数，比较冲突率 |
| **冲突处理方法比较** | 不同冲突处理方法下的平均查找长度(ASL)对比 |

### 1.3 约束条件

- 数据量 ≥ 30条
- 存储结构必须使用哈希表
- 支持中英文姓名
- 界面友好，支持反复操作

## 二、数据结构设计

### 2.1 核心结构

```
Customer（顾客信息）
├── name[32]      — 姓名
├── id[19]        — 身份证号
├── phone[12]     — 手机号
└── call_count    — 通话次数

哈希表 — 开放寻址法：OASlot[]
├── valid         — 状态：0=空, 1=占用, 2=删除
└── cust_idx      — 指向 customers[] 下标

哈希表 — 链地址法：ChainNode*[]
├── cust_idx      — 指向 customers[] 下标
└── next          — 同义词链表指针
```

### 2.2 哈希表参数

| 参数 | 值 | 依据 |
|------|-----|------|
| 顾客容量 | 100 | 题目要求 ≥30，留有余量 |
| 通话容量 | 500 | 足够覆盖测试数据 |
| 手机号哈希表大小 | **61** | 质数，减少聚集 |
| 姓名哈希表大小 | **61** | 质数，减少聚集 |
| 装填因子（30条） | 0.49 | 在合理范围内 |
| 装填因子（50条） | 0.82 | 接近警戒线 |

## 三、算法描述

### 3.1 算法一览

```
┌──────────────────────────────────────┐
│              程序入口                 │
├──────────────────────────────────────┤
│ ① 加载数据：load_customers()         │
│             load_calls()              │
│ ② 统计通话：count_calls()   O(n×m)  │
│ ③ 构建哈希表：ch_init() + 插入循环   │
│ ④ 菜单循环 ──────────────────────┐   │
│    ├─ 1. 聊天狂人     O(n)        │   │
│    ├─ 2. 按姓名查询   O(1+m)      │   │
│    ├─ 3. 按手机号查询 O(1)        │   │
│    ├─ 4. 冲突率比较   O(n)        │   │
│    ├─ 5. ASL比较      O(n)        │   │
│    └─ 0. 退出                      │   │
└──────────────────────────────────────┘
```

### 3.2 哈希函数设计

#### 方法一：除留余数法 `h(key) = key mod m`

- **手机号**：11位数字 → `unsigned long` → 对61取模
- **姓名**：每个字符 → `v = v*31 + c` → 对61取模
  - 乘数31是素数，可优化为 `(v << 5) - v`

#### 方法二：折叠法

- **手机号**：拆分为前3位 + 中4位 + 后4位 → 求和 → 对61取模
- **姓名**：每4字符一组 → 各组合并后累加 → 对61取模

### 3.3 冲突处理方法

| 方法 | 实现 | 插入 | 查找 | 删除 |
|------|------|------|------|------|
| **开放寻址法** | 线性探测 | O(1)均摊 | O(1)均摊 | 逻辑删除（valid=2） |
| **链地址法** | 头插法单链表 | O(1) | O(1)均摊 | 链表节点删除 |

### 3.4 复杂度分析

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 哈希计算 | O(L) | L = 关键字长度 |
| 插入 | O(1) 均摊 | 冲突时退化 |
| 查找 | O(1) 均摊 | 冲突时退化 |
| 统计通话 | O(N × M) | N=顾客数, M=通话数 |
| 查找狂人 | O(N × M) | 含统计步骤 |

### 4.2 预期测试结果

#### "聊天狂人"预期

| 排名 | 手机号 | 姓名 | 预计通话次数 |
|------|--------|------|-------------|
| 1 | 13800138001 | ZhangWei/张伟 | **12次** |
| 2 | 13800138002 | LiNa/李娜 | **8次** |
| 3 | 13800138003 | WangFang/王芳 | **4次** |

#### 冲突率预期（30条，表长61）

| 关键字 | 哈希方法 | 预期冲突率 |
|--------|---------|-----------|
| 手机号 | 除留余数法 | ~27%-33% |
| 手机号 | 折叠法 | ~30%-40% |
| 姓名 | 除留余数法 | ~17%-27% |
| 姓名 | 折叠法 | ~20%-30% |

#### ASL预期

| 关键字 | 处理方法 | 理论ASL | 预期范围 |
|--------|---------|---------|---------|
| 手机号 | 线性探测 | 1.48 | 1.3-1.8 |
| 手机号 | 链地址法 | 1.25 | 1.1-1.5 |
| 姓名 | 线性探测 | 1.48 | 1.3-1.8 |
| 姓名 | 链地址法 | 1.25 | 1.1-1.5 |

> ASL公式：线性探测 `(1+1/(1-α))/2`，链地址 `1+α/2`，其中 α=装填因子
