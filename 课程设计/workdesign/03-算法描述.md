# 题目3：电话"聊天狂人"查询系统 —— 算法描述

## 一、算法总览

```
程序启动
  │
  ├─ 1. load_customers("customers.txt")  ── 从文件加载顾客信息到数组
  ├─ 2. load_calls("calls.txt")          ── 从文件加载通话记录到数组
  ├─ 3. count_calls()                    ── 统计每位顾客的通话次数
  ├─ 4. ch_init() × 2                    ── 初始化两个链地址哈希表
  ├─ 5. ch_insert_*() × N                ── 将所有顾客插入哈希表
  │
  └─ 6. 菜单循环 ── 根据用户选择执行不同功能
        ├─ 1 → find_maniac()
        ├─ 2 → find_by_name()
        ├─ 3 → find_by_phone()
        ├─ 4 → compare_hash_functions()
        ├─ 5 → compare_collision_methods()
        └─ 0 → 退出
```

## 二、哈希函数算法

### 2.1 除留余数法（Division Method）

**原理**：`h(key) = key mod m`，其中 m 为不大于表长的质数。

#### 2.1.1 手机号关键字

```
算法: hash_div_phone(phone, size)
输入: phone  = 11位手机号字符串（如 "13800138001"）
      size   = 哈希表大小（61）
输出: 哈希地址（0 ~ size-1）

步骤:
  1. 将11位数字字符串转换为 unsigned long 整数
     v = 0
     for i = 0 to 10:
         v = v * 10 + (phone[i] - '0')
     结果: v = 13800138001

  2. 取模: return v % size
     示例: 13800138001 % 61 = ？
     计算: 13800138001 ÷ 61 = 226231770...余数
     C语言: (unsigned long)13800138001 % 61
```

**时间复杂度**：O(L)，L = 11（手机号长度）
**空间复杂度**：O(1)

#### 2.1.2 姓名关键字

```
算法: hash_div_name(name, size)
输入: name = 姓名字符串（如 "ZhangWei"）
      size = 哈希表大小（61）
输出: 哈希地址（0 ~ size-1）

步骤:
  1. 将字符串转换为 unsigned long 整数（多项式哈希）
     v = 0
     for each char c in name:
         v = v * 31 + (unsigned char)c
     // 31是素数，乘法可优化为 (v << 5) - v

  2. 取模: return v % size
```

**为何选择乘数31？**
- 31是素数，能减少哈希聚集
- `v * 31` 可被编译器优化为 `(v << 5) - v`（移位+减法，比乘法快）
- 被广泛用于Java String.hashCode()等标准实现

**时间复杂度**：O(L)，L = 姓名长度
**空间复杂度**：O(1)

### 2.2 折叠法（Folding Method）

**原理**：将关键字分割成若干段，各段相加后取模。

#### 2.2.1 手机号关键字

```
算法: hash_fold_phone(phone, size)
输入: phone = 11位手机号字符串
      size  = 哈希表大小
输出: 哈希地址

步骤:
  1. 将手机号分为三段:
     - 前3位 (p1): phone[0..2]  → 网络识别号
     - 中4位 (p2): phone[3..6]  → 地区编码
     - 后4位 (p3): phone[7..10] → 用户号码

  2. 每段转为整数后相加:
     sum = p1 + p2 + p3

  3. 取模: return sum % size

示例: "13800138001"
  p1 = 138
  p2 = 0013 = 13
  p3 = 8001
  sum = 138 + 13 + 8001 = 8152
  h = 8152 % 61 = ?
```

**时间复杂度**：O(L)，L = 11
**空间复杂度**：O(1)

#### 2.2.2 姓名关键字

```
算法: hash_fold_name(name, size)
输入: name = 姓名字符串
      size = 哈希表大小
输出: 哈希地址

步骤:
  1. 将字符串按每4个字符一组分段
  2. 每组转换为整数: chunk = Σ(字符ASCII × 256^pos)
  3. 各组累加: sum += chunk
  4. 取模: return sum % size

示例: "ZhangWei" (8个字符)
  组1: "Zhan" → chunk1
  组2: "gWei" → chunk2
  sum = chunk1 + chunk2
  h = sum % 61
```

**时间复杂度**：O(L)，L = 姓名长度
**空间复杂度**：O(1)

### 2.3 统一哈希接口

```c
// 通过 htype 参数选择哈希函数
static int hash_phone(const char *phone, int size, int htype) {
    return htype == HASH_DIV ? hash_div_phone(phone, size)
                             : hash_fold_phone(phone, size);
}
```

## 三、冲突处理方法算法

### 3.1 开放寻址法 —— 线性探测

#### 3.1.1 插入算法

```
算法: oa_insert_phone(table, size, cust_idx, htype)
输入: table[]  = OASlot数组（开放寻址哈希表）
      size     = 表长
      cust_idx = 顾客在 customers[] 中的下标
      htype    = 哈希函数类型（除留余数法 or 折叠法）
输出: 探测次数（用于统计）

步骤:
  1. h = hash_phone(customers[cust_idx].phone, size, htype)

  2. probe = 1
     for step = 0 to size-1:
         pos = (h + step) % size          // 线性探测序列
         probe++

         if table[pos].valid != 1:        // 空位或已删除位
             table[pos].valid = 1         // 标记为占用
             table[pos].cust_idx = cust_idx
             return probe                 // 返回探测次数

  3. return probe  // 表满（理论上不应到达）
```

**探测序列示例**（h=5, size=61）：
```
5, 6, 7, 8, ..., 60, 0, 1, 2, 3, 4
```

**特点**：
- 优点：实现简单，数组连续存储，缓存友好
- 缺点：可能产生**一次聚集**（primary clustering）

#### 3.1.2 查找算法

```
算法: oa_find_phone(table, size, phone, htype)
输入: table[] = OASlot数组
      phone   = 待查找手机号字符串
输出: 顾客下标（-1表示未找到）

步骤:
  1. h = hash_phone(phone, size, htype)

  2. for step = 0 to size-1:
         pos = (h + step) % size

         if table[pos].valid == 0:        // 遇到空位（从未使用）
             return -1                     // 查找失败

         if table[pos].valid == 1 AND
            strcmp(customers[table[pos].cust_idx].phone, phone) == 0:
             return table[pos].cust_idx   // 查找成功

  3. return -1  // 遍历整表未找到
```

**关键细节**：遇到`valid == 0`立即返回失败，因为如果有该关键字且发生冲突，线性探测不会跳过空位去存放。

### 3.2 链地址法（拉链法）

#### 3.2.1 插入算法

```
算法: ch_insert_phone(table, size, cust_idx, htype)
输入: table[]  = 链表头指针数组
      size     = 表长
      cust_idx = 顾客下标
      htype    = 哈希函数类型
输出: 该桶的链表长度（用于统计ASL）

步骤:
  1. h = hash_phone(customers[cust_idx].phone, size, htype)

  2. 创建新节点:
     node = malloc(sizeof(ChainNode))
     node->cust_idx = cust_idx
     node->next = table[h]     // 头插法
     table[h] = node

  3. 统计该桶链表长度:
     len = 0
     p = table[h]
     while p != NULL:
         len++
         p = p->next
     return len
```

**头插法示意**：
```
插入前: table[h] → [A] → [B] → NULL
插入后: table[h] → [NEW] → [A] → [B] → NULL
```

**特点**：
- 优点：装填因子可大于1，删除简单，无聚集问题
- 缺点：需要额外指针空间，节点内存不连续（缓存不友好）

#### 3.2.2 查找算法

```
算法: ch_find_phone(table, size, phone, htype)
输入: table[] = 链表头指针数组
      phone   = 待查找手机号
输出: 顾客下标（-1表示未找到）

步骤:
  1. h = hash_phone(phone, size, htype)

  2. p = table[h]
     while p != NULL:
         if strcmp(customers[p->cust_idx].phone, phone) == 0:
             return p->cust_idx    // 查找成功
         p = p->next

  3. return -1  // 遍历链表未找到
```

## 四、核心功能算法

### 4.1 统计通话次数

```
算法: count_calls()
输入: 全局数组 customers[], call_from[][], call_to[][]
输出: 更新每位顾客的 call_count

步骤:
  1. for i = 0 to cust_cnt-1:
         customers[i].call_count = 0      // 清零

  2. for k = 0 to call_cnt-1:             // 遍历每条通话记录
         for i = 0 to cust_cnt-1:         // 遍历每位顾客
             if customers[i].phone == call_from[k]:
                 customers[i].call_count++  // 作为主叫
             if customers[i].phone == call_to[k]:
                 customers[i].call_count++  // 作为被叫
```

**时间复杂度**：O(N × M)，N=cust_cnt，M=call_cnt
**优化可能**：先用哈希表建立"手机号→顾客下标"映射，则复杂度降为O(M)

### 4.2 查找"聊天狂人"

```
算法: find_maniac()
输出: 显示通话次数最多的用户信息

步骤:
  1. count_calls()  // 重新统计（确保数据最新）

  2. best = 0
     for i = 1 to cust_cnt-1:
         if customers[i].call_count > customers[best].call_count:
             best = i

  3. 输出 customers[best] 的姓名、手机号、通话次数
```

**时间复杂度**：O(N × M + N) → 主要开销在count_calls()

### 4.3 按姓名查找

```
算法: find_by_name(name)
输入: name = 待查找姓名
输出: 用户信息、通话详情（含主叫/被叫明细）

步骤:
  1. idx = ch_find_name(name_ch, NAME_TABLE_SIZE, name, HASH_DIV)
     // 在链地址法姓名哈希表中查找

  2. if idx < 0:
         输出 "No Info"
         return

  3. 输出 customers[idx] 基本信息（姓名、身份证、手机号、通话次数）

  4. 遍历 calls 数组，输出该用户的所有通话记录:
     for k = 0 to call_cnt-1:
         if call_from[k] == customers[idx].phone:
             输出 "[主叫] -> {call_to[k]}"
         if call_to[k] == customers[idx].phone:
             输出 "[被叫] <- {call_from[k]}"
```

**时间复杂度**：
- 哈希查找：O(1) 均摊
- 遍历通话记录：O(M)，M=call_cnt

### 4.4 哈希函数冲突率比较

```
算法: compare_hash_functions()
输出: 两种哈希函数在手机号和姓名上的冲突率对比

步骤:
  1. 使用临时开放寻址表，分别以 HASH_DIV 和 HASH_FOLD 重建手机号哈希表

  2. 统计每种配置的冲突次数:
     collisions = 插入时探测次数 > 1 的次数
     冲突率 = collisions / inserted × 100%

  3. 对姓名哈希表重复上述过程

  4. 以表格形式输出四种组合的冲突率对比
```

### 4.5 冲突处理方法ASL比较

```
算法: compare_collision_methods()
输出: 开放寻址法和链地址法的ASL对比

步骤:
  1. 使用 HASH_DIV（除留余数法）作为统一哈希函数

  2. 分别构建手机号的开放寻址表和链地址表
     记录: total_probe（总探测次数）、inserted（插入数）

  3. 计算ASL:
     ASL_成功 = total_probe / inserted

  4. 对姓名哈希表重复上述过程

  5. 以表格形式输出四种组合的ASL对比
```

## 五、各算法复杂度汇总

| 算法 | 时间复杂度 | 空间复杂度 | 备注 |
|------|-----------|-----------|------|
| 除留余数哈希 | O(L) | O(1) | L=关键字长度 |
| 折叠法哈希 | O(L) | O(1) | L=关键字长度 |
| 开放寻址插入 | O(1)均摊 | O(1) | 最坏O(n) |
| 开放寻址查找 | O(1)均摊 | O(1) | 最坏O(n) |
| 链地址插入 | O(1) | O(1) | 头插法 |
| 链地址查找 | O(1)均摊 | O(1) | 最坏O(n) |
| count_calls | O(N×M) | O(1) | N=顾客数, M=通话数 |
| find_maniac | O(N×M) | O(1) | 含count_calls |
| find_by_name | O(1+M) | O(1) | 哈希+遍历 |
| 冲突率比较 | O(N) | O(m) | m=表长 |
| ASL比较 | O(N) | O(m) | m=表长 |
