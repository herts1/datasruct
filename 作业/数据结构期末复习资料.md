### 第一章 绪论

#### 核心概念

**1. 数据结构三要素：**
- **逻辑结构**：数据元素之间的逻辑关系
  - 线性结构：线性表、栈、队列、串
  - 非线性结构：树、图、集合
- **存储结构（物理结构）**：数据结构在计算机中的存储表示
  - 顺序存储：逻辑相邻 → 物理相邻
  - 链式存储：通过指针链接
  - 索引存储：附加索引表
  - 散列存储：通过哈希函数计算地址
- **数据运算**：对数据的操作（查找、插入、删除等）

**2. 算法分析：**

| 复杂度 | 含义 |
|--------|------|
| **时间复杂度** | 算法运行时间随问题规模 $n$ 增长的趋势 |
| **空间复杂度** | 算法运行时所需额外空间随 $n$ 增长的趋势 |

**常见时间复杂度增长率排序（低→高）：**
$$O(1) < O(log₂ n) < O(n) < O(n log₂ n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)$$

**三种时间复杂度区分：**
- **最好时间复杂度**：最理想情况
- **最坏时间复杂度**：最糟糕情况（通常以此为准）
- **平均时间复杂度**：所有情况按概率加权平均

**递归函数的空间复杂度**：等于递归深度 × 每层空间开销

#### 📝 自测题

1. 以下属于线性结构的是（ ）
   A. 树  B. 图  C. 栈  D. 集合

2. 以下不属于算法的基本特性的是（ ）
   A. 有穷性  B. 确定性  C. 可行性  D. 无限性

3. 某算法的时间复杂度为 $O(n^2)$，当 $n=100$ 时执行时间为 1ms，则 $n=1000$ 时执行时间约为多少？

4. 分析以下递归函数的空间复杂度：
```c
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
```

<details>
<summary>📋 点击查看答案</summary>

**1.** C（栈是线性结构；树和图是非线性结构；集合通常是独立于线性/非线性的逻辑结构）

**2.** D（算法的基本特性：有穷性、确定性、可行性、输入、输出。没有"无限性"）

**3.** 约 **100ms**。时间 $T(n) ∝ n²$，$T(1000) / T(100) = 1000² / 100² = 100$，所以 $T(1000) ≈ 1ms × 100 = 100ms$

**4.** 空间复杂度为 **$O(n)$**。递归深度 = n（fact(n) → fact(n-1) → ... → fact(1)），每次调用占用常量空间，总空间 = 递归深度 × 每层开销 = $O(n)$

</details>

### 第二章 线性表

#### 核心概念

**1. 顺序表 vs 链表：**

| 特性 | 顺序表 | 链表 |
|------|--------|------|
| 存储方式 | 连续存储单元 | 结点通过指针链接 |
| 随机访问 | **支持** $O(1)$ | 不支持，需遍历 $O(n)$ |
| 插入/删除 | 需移动元素 $O(n)$ | 只需修改指针 $O(1)$（已定位） |
| 存储密度 | 高（仅存数据） | 低（数据+指针） |
| 空间分配 | 静态/动态，需预分配 | 动态，按需分配 |

**2. 带头结点单链表的常见操作：**

```c
// 定义结点结构
typedef struct LNode {
    int data;               // 数据域
    struct LNode *next;     // 指针域
} LNode, *LinkList;

// (1) 头插法建立链表（逆序）
void CreateList_Head(LinkList *L, int a[], int n) {
    *L = (LinkList)malloc(sizeof(LNode));
    (*L)->next = NULL;  // 头结点
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode*)malloc(sizeof(LNode));
        s->data = a[i];
        s->next = (*L)->next;
        (*L)->next = s;
    }
}
// 时间复杂度: O(n)

// (2) 尾插法建立链表（正序）
void CreateList_Tail(LinkList *L, int a[], int n) {
    *L = (LinkList)malloc(sizeof(LNode));
    LNode *r = *L;  // 尾指针
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode*)malloc(sizeof(LNode));
        s->data = a[i];
        r->next = s;
        r = s;
    }
    r->next = NULL;
}

// (3) 按值查找
LNode* LocateElem(LinkList L, int e) {
    LNode *p = L->next;
    while (p != NULL && p->data != e)
        p = p->next;
    return p;  // 返回结点指针，不存在则返回NULL
}
// 时间复杂度: O(n)

// (4) 插入结点（在p之后插入值为e的结点）
void InsertAfter(LNode *p, int e) {
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;
    p->next = s;
}
// 时间复杂度: O(1)

// (5) 删除结点（删除p的后继结点）
void DeleteAfter(LNode *p) {
    LNode *q = p->next;
    p->next = q->next;
    free(q);
}
// 时间复杂度: O(1)
```

**3. 有序表上的操作：**
- 插入：需要先找到位置再插入，$O(n)$
- 删除：遍历找到元素后删除，$O(n)$
- 合并两个有序表：双指针法，$O(m+n)$

#### 📝 自测题

1. 在含 n 个元素的顺序表中，在第 i 个位置插入新元素需要移动多少个元素？

2. 在单链表中删除结点 p 的后继结点的前提是？

3. 写出合并两个递增有序单链表为一个递减有序单链表的算法思路。

4. 已知顺序表 L 长度为 n，删除所有值为 x 的元素。要求时间 $O(n)$，空间 $O(1)$。

<details>
<summary>📋 点击查看答案</summary>

**1.** **$n-i+1$** 个元素。插入位置 i 及其之后的元素都要后移一位，共移动 $(n-i+1)$ 个。

**2.** 前提是 **p 的后继结点存在**，即 `p->next != NULL`。

**3.** 算法思路：
- 同时遍历两个递增链表 A 和 B
- 每次比较 A 和 B 当前结点的值，**取较小者**用**头插法**插入新链表 C
- 遍历完一个链表后，将另一个链表剩余部分继续头插到 C
- 头插法自然实现了逆序（递减）

```c
// 合并两个递增有序链表为一个递减有序链表
LinkList MergeDesc(LinkList A, LinkList B) {
    LinkList C = (LinkList)malloc(sizeof(LNode));
    C->next = NULL;  // C使用头插法
    LNode *pa = A->next, *pb = B->next, *q;
    while (pa && pb) {
        if (pa->data <= pb->data) {
            q = pa; pa = pa->next;
        } else {
            q = pb; pb = pb->next;
        }
        q->next = C->next;  // 头插
        C->next = q;
    }
    // 处理剩余部分
    while (pa) {
        q = pa; pa = pa->next;
        q->next = C->next; C->next = q;
    }
    while (pb) {
        q = pb; pb = pb->next;
        q->next = C->next; C->next = q;
    }
    return C;
}
```

**4.** 使用双指针（快慢指针）：
```c
void DeleteX(SeqList *L, int x) {
    int k = 0;  // 记录不等于x的元素个数
    for (int i = 0; i < L->length; i++) {
        if (L->data[i] != x)
            L->data[k++] = L->data[i];
    }
    L->length = k;
}
```
时间复杂度 $O(n)$，空间复杂度 $O(1)$。核心思想：不等于 x 的元素往前覆盖，等于 x 的元素跳过。

</details>

### 第三章 栈和队列

#### 核心概念

**1. 栈 vs 队列：**

| 特性 | 栈 (Stack) | 队列 (Queue) |
|------|-----------|-------------|
| 逻辑 | LIFO（后进先出） | FIFO（先进先出） |
| 操作端 | 一端（栈顶） | 两端（队头出、队尾入） |
| 基本操作 | push, pop, top | enQueue, deQueue, front |
| 应用 | 递归、括号匹配、表达式求值 | BFS、缓冲区、排队系统 |

**2. 链式队列的常用操作：**

```c
// 链式队列结点定义
typedef struct QNode {
    int data;
    struct QNode *next;
} QNode;

typedef struct {
    QNode *front;  // 队头指针
    QNode *rear;   // 队尾指针
} LinkQueue;

// 入队
void EnQueue(LinkQueue *Q, int e) {
    QNode *s = (QNode*)malloc(sizeof(QNode));
    s->data = e;
    s->next = NULL;
    Q->rear->next = s;
    Q->rear = s;
}

// 出队
int DeQueue(LinkQueue *Q) {
    QNode *p = Q->front->next;
    int e = p->data;
    Q->front->next = p->next;
    if (Q->rear == p) Q->rear = Q->front;  // 队空
    free(p);
    return e;
}
```

**3. 循环队列（顺序队列）——重点！：**

循环队列是将顺序队列的首尾相连，解决顺序队列"假溢出"问题。

```c
// 循环队列定义
#define MAXSIZE 100
typedef struct {
    int data[MAXSIZE];
    int front;  // 队头指针（指向队头元素）
    int rear;   // 队尾指针（指向队尾元素的下一个位置）
} SqQueue;
```

**循环队列空/满判断的三种方式：**

| 方式 | 队空条件 | 队满条件 | 说明 |
|------|----------|----------|------|
| **① 牺牲一个单元** | `front == rear` | `(rear + 1) % MAXSIZE == front` | **最常用**，实际容量 = MAXSIZE - 1 |
| **② 增设计数变量** | `count == 0` | `count == MAXSIZE` | 单独维护元素个数 |
| **③ 增设 tag 标记** | `front == rear && tag == 0` | `front == rear && tag == 1` | tag=0 表示上次是出队，tag=1 表示上次是入队 |

> ⚠️ **考点**：方式①中，`front == rear` 既可能是队空也可能是队满，因此需要牺牲一个存储单元来区分两者。考试常考判断题/选择题。

**循环队列基本操作：**

```c
// 初始化
void InitQueue(SqQueue *Q) {
    Q->front = 0;
    Q->rear = 0;
}

// 判空
int QueueEmpty(SqQueue Q) {
    return Q.front == Q.rear;  // 1=空, 0=非空
}

// 判满（方式①：牺牲一个单元）
int QueueFull(SqQueue Q) {
    return (Q.rear + 1) % MAXSIZE == Q.front;  // 1=满, 0=未满
}

// 入队
int EnQueue(SqQueue *Q, int e) {
    if ((Q->rear + 1) % MAXSIZE == Q->front)
        return 0;  // 队满，无法入队
    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAXSIZE;
    return 1;
}

// 出队
int DeQueue(SqQueue *Q, int *e) {
    if (Q->front == Q->rear)
        return 0;  // 队空，无法出队
    *e = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    return 1;
}

// 求队列长度（元素个数）
int QueueLength(SqQueue Q) {
    return (Q.rear - Q.front + MAXSIZE) % MAXSIZE;
}
```

**循环队列常见考点速记：**

| 考点 | 答案 |
|------|------|
| 队满条件（牺牲一个单元） | `(rear + 1) % MAXSIZE == front` |
| 队空条件 | `front == rear` |
| 元素个数 | `(rear - front + MAXSIZE) % MAXSIZE` |
| 实际最大容量 | `MAXSIZE - 1` |
| rear 指针移动 | `rear = (rear + 1) % MAXSIZE` |
| front 指针移动 | `front = (front + 1) % MAXSIZE` |

**4. 栈解决表达式求值问题：**
- **中缀转后缀**：操作数直接输出，运算符比较优先级入栈
- **后缀求值**：操作数入栈，遇到运算符则弹出两个操作数计算后入栈

**5. 递归与队列应用（BFS/遍历搜索）：**
- 递归本质是系统栈的使用
- 队列用于广度优先搜索（BFS），如二叉树的层序遍历

#### 📝 自测题

1. 后缀表达式 `3 4 + 5 * 6 2 / -` 的值为多少？

2. 用栈实现以下中缀表达式转为后缀：`a + b * (c - d) / e`

3. 循环队列存储在 A[0..m-1] 中，front 指向队头元素，rear 指向队尾元素的下一个位置。问：(1) 队空的条件是什么？(2) 队满的条件是什么？(3) 队列中元素个数的计算公式是什么？

4. 简述如何用两个栈实现一个队列。

<details>
<summary>📋 点击查看答案</summary>

**1.** 值为 **32**。

计算过程：
- `3 4 +` → 3+4=7，栈：[7]
- `5 *` → 7×5=35，栈：[35]
- `6 2 /` → 6/2=3，栈：[35, 3]
- `-` → 35-3=**32**

**2.** 转换结果为：**`a b c d - * e / +`**

步骤：
| 扫描 | 栈（运算符） | 输出 |
|------|-------------|------|
| a | (空) | a |
| + | + | a |
| b | + | a b |
| * | + * | a b |
| ( | + * ( | a b |
| c | + * ( | a b c |
| - | + * ( - | a b c |
| d | + * ( - | a b c d |
| ) | + * | a b c d - |
| / | + / | a b c d - * |
| e | + / | a b c d - * e |
| 结束 | (空) | a b c d - * e / + |

**3.** (1) 队空条件：**`front == rear`**
(2) 队满条件（牺牲一个单元）：**`(rear + 1) % m == front`**
(3) 元素个数：**`(rear - front + m) % m`**

> 💡 记忆口诀：空是 front 追 rear，满是 rear 追 front。rear 始终指向"下一个空位"。

**4.** 用两个栈实现队列：
- **栈A**负责入队（push），**栈B**负责出队（pop）
- **入队**：直接 push 到栈A
- **出队**：若栈B非空，pop栈B；若栈B为空，将栈A全部弹出并压入栈B，再pop栈B
- 每个元素最多被push和pop两次，所以**均摊时间复杂度为 O(1)**

</details>

### 第四章 串

#### 核心概念

**1. 串的基本概念：**
- 串是由零个或多个字符组成的有限序列
- 空串 vs 空白串：空串长度为0，空白串由一个或多个空格组成

**2. BF算法（暴力匹配）：**
- 主串 S，模式串 T
- 时间复杂度：最好 $O(n+m)$，最坏 $O(n × m)$

**3. KMP算法：**
- 利用已匹配部分的信息避免回溯
- 时间复杂度：$O(n+m)$
- 核心：**next数组**

```c
// 求next数组
void getNext(char T[], int next[]) {
    int j = 0, k = -1;
    next[0] = -1;
    while (j < strlen(T) - 1) {
        if (k == -1 || T[j] == T[k]) {
            j++; k++;
            next[j] = k;
        } else {
            k = next[k];
        }
    }
}

// 求nextval数组（优化版）
void getNextVal(char T[], int nextval[]) {
    int j = 0, k = -1;
    nextval[0] = -1;
    while (j < strlen(T) - 1) {
        if (k == -1 || T[j] == T[k]) {
            j++; k++;
            if (T[j] != T[k])
                nextval[j] = k;
            else
                nextval[j] = nextval[k];
        } else {
            k = nextval[k];
        }
    }
}
```

### 第七章 树和二叉树

#### 核心概念

**1. 二叉树的基本性质（背！）：**

| 性质 | 内容 |
|------|------|
| 性质1 | 第 $i$ 层最多 $2^{i-1}$ 个结点（$i ≥ 1$） |
| 性质2 | 深度为 $k$ 最多 $2^k - 1$ 个结点 |
| 性质3 | $n_0 = n_2 + 1$（叶子数 = 度为2的结点数 + 1） |
| 性质4 | $n$ 个结点的完全二叉树深度为 $⌊log₂ n⌋ + 1$ |
| 性质5 | 完全二叉树中，编号 $i$ 的左孩子编号为 $2i$，右孩子为 $2i+1$，父结点为 $⌊i/2⌋$ |

**结点关系公式：**
- $n = n_0 + n_1 + n_2$（总结点数 = 度为0,1,2的结点之和）
- $n = n_1 + 2n_2 + 1$（总结点数 = 分支数 + 1）

**2. 完全二叉树特点：**
- 除最后一层外，每层都是满的
- 最后一层结点从左到右连续排列
- 可利用顺序存储

**3. 遍历方式及应用（重点！）：**

| 遍历方式 | 访问顺序 | PTA常见应用 |
|----------|----------|-------------|
| 先序（先根） | 根 → 左 → 右 | 复制二叉树、求深度 |
| 中序（中根） | 左 → 根 → 右 | 二叉排序树输出有序序列 |
| 后序（后根） | 左 → 右 → 根 | 释放结点、计算高度、求权值和 |
| 层序 | 从上到下，从左到右 | 使用**队列**实现（BFS） |

```c
// 先序遍历（递归）- 时间复杂度 O(n), 空间复杂度 O(h)
void PreOrder(BiTree T) {
    if (T != NULL) {
        visit(T);                 // 访问根
        PreOrder(T->lchild);      // 遍历左子树
        PreOrder(T->rchild);      // 遍历右子树
    }
}

// 中序遍历（非递归）- 使用栈
void InOrder(BiTree T) {
    Stack S; InitStack(&S);
    BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) { Push(&S, p); p = p->lchild; }
        else   { Pop(&S, &p); visit(p); p = p->rchild; }
    }
}

// 层序遍历 - 使用队列，时间复杂度 O(n)
void LevelOrder(BiTree T) {
    Queue Q; InitQueue(&Q);
    EnQueue(&Q, T);
    while (!QueueEmpty(Q)) {
        BiTree p = DeQueue(&Q);
        visit(p);
        if (p->lchild) EnQueue(&Q, p->lchild);
        if (p->rchild) EnQueue(&Q, p->rchild);
    }
}
```

**4. 二叉树的深度计算（高频考点！）：**

**(1) 递归法（后序遍历思想）：**

```c
int Depth(BiTree T) {
    if (T == NULL) return 0;
    int ld = Depth(T->lchild);  // 左子树深度
    int rd = Depth(T->rchild);  // 右子树深度
    return (ld > rd ? ld : rd) + 1;  // 取大者 +1
}
// 时间复杂度: O(n) — 每个结点访问一次
// 空间复杂度: O(h) — 递归栈深度，h为树高
```

**(2) 层序遍历法（非递归）：**

```c
int Depth_Level(BiTree T) {
    if (T == NULL) return 0;
    Queue Q; InitQueue(&Q);
    EnQueue(&Q, T);
    int depth = 0;
    while (!QueueEmpty(Q)) {
        int width = QueueLength(Q);  // 当前层的结点数
        depth++;
        for (int i = 0; i < width; i++) {
            BiTree p = DeQueue(&Q);
            if (p->lchild) EnQueue(&Q, p->lchild);
            if (p->rchild) EnQueue(&Q, p->rchild);
        }
    }
    return depth;
}
// 时间复杂度: O(n)
// 空间复杂度: O(w) — w为树的最大宽度
```

> 💡 对比：递归法代码简洁，是考试写算法的首选；层序法可同时求出每层宽度，适合需要"逐层处理"的场景。

**5. 二叉树的结点计数专题（必会算法！）：**

| 问题 | 遍历方式 | 核心判断条件 |
|------|----------|-------------|
| 求总结点数 | 先/后序 | 空返回0，否则返回 左计数 + 右计数 + 1 |
| 求叶子结点数 | 先/后序 | 左右均为空时返回1 |
| 求单分支结点数 | 先/后序 | 左右之一为空、另一非空时计数 |
| 求双分支结点数 | 先/后序 | 左右均非空时计数 |

```c
// 求总结点数
int NodeCount(BiTree T) {
    if (T == NULL) return 0;
    return NodeCount(T->lchild) + NodeCount(T->rchild) + 1;
}

// 求叶子结点数
int LeafCount(BiTree T) {
    if (T == NULL) return 0;
    if (T->lchild == NULL && T->rchild == NULL) return 1;
    return LeafCount(T->lchild) + LeafCount(T->rchild);
}

// 求单分支结点数
int SingleBranchCount(BiTree T) {
    if (T == NULL) return 0;
    int cnt = 0;
    if ((T->lchild == NULL && T->rchild != NULL) ||
        (T->lchild != NULL && T->rchild == NULL))
        cnt = 1;
    return cnt + SingleBranchCount(T->lchild) + SingleBranchCount(T->rchild);
}

// 求双分支结点数
int DoubleBranchCount(BiTree T) {
    if (T == NULL) return 0;
    int cnt = (T->lchild && T->rchild) ? 1 : 0;
    return cnt + DoubleBranchCount(T->lchild) + DoubleBranchCount(T->rchild);
}
```

**结点计数公式总结（配合性质3使用）：**

| 已知条件 | 可推导结果 |
|----------|-----------|
| 已知叶子数 $n_0$ | $n_2 = n_0 - 1$；若为完全二叉树，$n_1$ 为 0 或 1 |
| 已知边数 $e$ | 总结点数 $n = e + 1$ |
| 已知总度数之和 $D$ | $D = n - 1$（树）；$D = 2e$（无向图） |

**6. 由遍历序列确定二叉树：**
- **唯一确定**：先序+中序 或 后序+中序 或 层序+中序
- **不能唯一确定**：先序+后序（无法区分左右子树）

**方法**：先序/后序确定根节点，中序分左右子树，递归进行

**7. 线索二叉树：**
- 利用空链域（n个结点有 $2n-(n-1)=n+1$ 个空指针）存放线索
- **中序线索化**最常用：左空指向前驱，右空指向后继
- 线索化后遍历无需递归/栈，沿线索走即可 → 空间 $O(1)$

**8. 树、森林与二叉树的转换（常考画图！）：**

**树 → 二叉树（"左孩子右兄弟"）：**
1. 同一结点的所有孩子，用线连接起来（兄弟之间连线）
2. 保留每个结点与**第一个孩子**的连线，删除与其他孩子的连线
3. 以根为轴，将整棵树顺时针旋转 45°，使兄弟连线变成右子树

> 📌 口诀：**兄弟连成线，只留老大边，旋转四十五**

**二叉树 → 树（逆过程）：**
1. 对任意结点，其**左孩子**是它在原树中的**第一个孩子**
2. 沿左孩子的**右链**一直走，沿途结点都是原树中该结点的**兄弟（孩子）**

**森林 → 二叉树：**
1. 先将森林中每棵树分别转为二叉树
2. 从第一棵开始，将后一棵二叉树的根作为前一棵二叉树根的**右孩子**

**转换后的规律速记：**

| 原结构 | 转换后二叉树特征 |
|--------|-----------------|
| 树 | 根结点**无右子树** |
| 森林 | 根结点**有右子树** |
| 树中兄弟 | 二叉树中**右链上的结点** |
| 树中孩子 | 二叉树中**左孩子 + 其右链** |

**9. 哈夫曼树（重要简答题考点！）：**

构造步骤：
1. 将n个权值看作n棵只有根节点的二叉树，构成森林F
2. 从F中选**两棵根节点权值最小**的树作为左右子树，构造新二叉树（新树根权值=左右子树根权值之和）
3. 从F中删除被选的两棵树，加入新树
4. 重复步骤2-3直到F中只剩一棵树（n个叶子需合并 n-1 次）

**哈夫曼编码**：左分支编码0，右分支编码1（或反之，须一致）
- 哈夫曼编码是**前缀编码**（任何一个字符的编码都不是另一个字符编码的前缀）
- 带权路径长度 WPL = Σ(叶子权值 × 从根到叶子的路径长度)

**10. 二叉排序树（BST）——重要简答题考点！：**
- 定义：左子树所有值 < 根值 < 右子树所有值（或左<根≤右）
- 查找 $O(h)$，构建 $O(n\log n)$ 平均、$O(n^2)$ 最坏
- **中序遍历 BST 得到递增有序序列**

**BST 的 ASL 计算：**

$$ASL_{成功} = \frac{\sum_{i=1}^{n} (第i个结点的查找长度)}{n} = \frac{\sum_{i=1}^{n} (结点i所在层数)}{n}$$

> 查找长度 = 从根到目标结点路径上的结点数（含根和目标）

**BST 形态与效率的关系：**

| 形态 | 查找效率 | 对应情况 |
|------|---------|---------|
| 平衡 BST（左右子树高度差≤1） | $O(\log n)$ | 插入顺序均匀分布 |
| 退化为单链表 | $O(n)$ | 插入序列已有序（递增/递减） |

**BST 与二分查找判定树的关系：**
- 二分查找的判定树是一棵**平衡的 BST**
- 对同一组关键字，BST 形态不唯一，但二分查找判定树**唯一**

```c
int IsSimilar(BiTree T1, BiTree T2) {
    if (T1 == NULL && T2 == NULL) return 1;      // 都空→相似
    if (T1 == NULL || T2 == NULL) return 0;      // 一空一非空→不相似
    return IsSimilar(T1->lchild, T2->lchild) &&  // 左子树相似
           IsSimilar(T1->rchild, T2->rchild);     // 且右子树相似
}
```
- 时间复杂度：$O(\min(n_1, n_2))$
- 空间复杂度：$O(\min(h_1, h_2))$

**7.** 求二叉树深度：

**(1) 递归算法：**
```c
int Depth(BiTree T) {
    if (T == NULL) return 0;
    int ld = Depth(T->lchild);
    int rd = Depth(T->rchild);
    return (ld > rd ? ld : rd) + 1;
}
```

**(2) 层序遍历法（非递归）：**
```c
int Depth_Level(BiTree T) {
    if (T == NULL) return 0;
    Queue Q; InitQueue(&Q);
    EnQueue(&Q, T);
    int depth = 0;
    while (!QueueEmpty(Q)) {
        int width = QueueLength(Q);  // 当前层结点数
        depth++;
        for (int i = 0; i < width; i++) {
            BiTree p = DeQueue(&Q);
            if (p->lchild) EnQueue(&Q, p->lchild);
            if (p->rchild) EnQueue(&Q, p->rchild);
        }
    }
    return depth;
}
```

**两种方法对比：**

| 对比维度 | 递归法 | 层序法 |

| 空间复杂度 | $O(h)$（递归栈） | $O(w)$（队列，$w$ 为最大宽度） |
| 代码量 | 简洁（3行核心代码） | 稍长 |
| 额外能力 | 无法获取每层宽度 | 可同时求出每层结点数 |
| 适用场景 | 笔试写算法首选 | 需要逐层处理时使用 |

### 第八章 图

#### 核心概念

**1. 图的基本概念：**

| 概念 | 说明 |
|------|------|
| 无向图 | 边是无向的，$(v_i, v_j) = (v_j, v_i)$ |
| 有向图 | 边是有向的（弧），$<v_i, v_j> \neq <v_j, v_i>$ |
| 完全图 | 无向完全图 $\frac{n(n-1)}{2}$ 条边；有向完全图 $n(n-1)$ 条弧 |
| 度 | 无向图：$TD(v)$；有向图：$ID(v)$ 入度 + $OD(v)$ 出度 |
| 连通图 | 任意两顶点之间存在路径（无向图） |
| 强连通图 | 任意两顶点之间双向可达（有向图） |
| **边与结点关系** | 无向图 $\sum_{i=1}^n TD(v_i) = 2e$；有向图 $\sum ID = \sum OD = e$ |

**2. 图的存储结构（重点！）：**

**邻接矩阵：**
- $n × n$ 的矩阵，有边为1/权值，无边为0/∞
- 空间复杂度 $O(n^2)$，适合稠密图
- 无向图的邻接矩阵是对称的

**邻接表：**
- 每个顶点一个单链表，存储该顶点的所有邻接点
- 空间复杂度 $O(n+e)$（无向图 $O(n+2e)$），适合稀疏图
- 不便于判断两顶点间是否有边

**邻接矩阵 ↔ 邻接表互转：** 遍历邻接矩阵/邻接表，按另一形式输出

**3. 图的遍历：**

| 遍历方式 | 辅助结构 | 核心思想 | 时间复杂度 |
|----------|----------|----------|-----------|
| 深度优先 DFS | **栈**（递归） | 沿一条路径走到底再回溯 | 邻接矩阵 $O(n^2)$ / 邻接表 $O(n+e)$ |
| 广度优先 BFS | **队列** | 先访问所有邻接点再深入 | 邻接矩阵 $O(n^2)$ / 邻接表 $O(n+e)$ |

**4. 最小生成树（简答题考点！）：**

| 算法 | 思想 | 适用 | 时间复杂度 |
|------|------|------|-----------|
| **Prim（普里姆）** | 从点出发，选最小边加入 | 稠密图 | $O(n^2)$ |
| **Kruskal（克鲁斯卡尔）** | 从边出发，不形成回路就加入 | 稀疏图 | $O(e\log e)$ |

**手动执行步骤：**
- Prim：选一个起点 → 在所有连接已选集合与未选集合的边中选最小权值的边 → 重复 $n-1$ 次
- Kruskal：所有边按权值排序 → 从小到大选边，不构成回路就加入 → 选够 $n-1$ 条

**5. 最短路径 Dijkstra（简答题考点！）：**
- 单源最短路径，适用**非负权值**图
- 核心：每次选当前距离最小且未确定的顶点，更新其邻接点距离
- 时间复杂度：$O(n^2)$（邻接矩阵）

**6. 拓扑排序：**
- 仅针对 **AOV网**（有向无环图）
- 方法：每次选入度为0的顶点输出，删除其所有出边，重复
- 拓扑序列不唯一
- 若图中存在回路，则无法输出所有顶点

    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            Matrix[i][j] = 0;

    // 遍历邻接表
    for (int i = 0; i < n; i++) {

}

### 第九章 查找

#### 核心概念

**1. 折半查找（二分查找）：**
- **前提**：有序顺序存储
- 时间复杂度：$O(log₂ n)$
- 判定树是平衡二叉排序树
- 查找成功/失败的平均比较次数 ≠ ASL

**2. 二叉排序树（BST）：**

```c
// BST查找（递归）
BSTNode* SearchBST(BSTree T, int key) {
    if (T == NULL || T->data == key) return T;
    if (key < T->data) return SearchBST(T->lchild, key);
    else               return SearchBST(T->rchild, key);
}

// BST插入
void InsertBST(BSTree *T, int key) {
    if (*T == NULL) {
        *T = (BSTree)malloc(sizeof(BSTNode));
        (*T)->data = key;
        (*T)->lchild = (*T)->rchild = NULL;
    } else if (key < (*T)->data) {
        InsertBST(&((*T)->lchild), key);
    } else {
        InsertBST(&((*T)->rchild), key);
    }
}
```

**BST删除的三种情况：**
| 被删结点情况 | 处理方法 |
|-------------|---------|
| 叶子结点 | 直接删除 |
| 只有左子树或只有右子树 | 用子树替代 |
| 有左右子树 | 用直接前驱（左子树最大）或直接后继（右子树最小）替代 |

**3. 哈希表（简答题重点考点！）：**

**基本概念：**
- 哈希函数：将关键字映射到地址
- 冲突：不同关键字映射到同一地址
- 装填因子 $\alpha = n/m$（n=元素个数，m=表长）

**冲突处理方法：**
- **开放定址法**：
  - 线性探测：$H_i = (H(key) + i) \bmod m, i=1,2,\cdots$
  - 二次探测：$H_i = (H(key) \pm i^2) \bmod m$
- **链地址法**：同义词存于同一链表

**ASL 计算（等概率情况）：**

$$ASL_{成功} = \frac{\sum 每个关键字的比较次数}{关键字总数}$$

$$ASL_{不成功} = \frac{\sum 每种哈希地址对应的比较次数}{表长（或模数）}$$

> 计算不成功ASL时，关键是明确"每种哈希地址"对应探测多少次才能确定"查找失败"

### 第十章 内部排序

#### 核心概念

**各排序算法总结表（重点记！）：**

| 排序算法 | 最好时间 | 最坏时间 | 平均时间 | 空间复杂度 | 稳定性 | 存储适应性 |
|----------|----------|----------|----------|------------|--------|-----------|
| 直接插入排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✅稳定 | 顺序/链式 |
| 折半插入排序 | $O(n\log n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✅稳定 | 顺序 |
| **希尔排序** | — | $O(n^2)$ | $O(n^{1.3})$ | $O(1)$ | ❌不稳定 | 顺序 |
| 简单选择排序 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ❌不稳定 | 顺序/链式 |
| 堆排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | ❌不稳定 | 顺序 |
| 冒泡排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✅稳定 | 顺序/链式 |
| **快速排序** | $O(n\log n)$ | $O(n^2)$ | $O(n\log n)$ | $O(\log n)$ | ❌不稳定 | 顺序 |
| 归并排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | ✅稳定 | 顺序/链式 |

**初始序列状态对算法的影响：**
- 直接插入排序：基本有序时效率高（接近 $O(n)$）
- 快速排序：基本有序时退化到 $O(n^2)$（选两端为基准时）
- 冒泡排序：基本有序时效率高（可提前结束）

**重点细节：**

**1. 希尔排序（重点掌握！）：**
- 将序列按增量分组，每组内直接插入排序
- 增量递减（如 d = n/2 → n/4 → ... → 1）
- 最后一趟增量必须为 **1**

**2. 快速排序（重点掌握！）：**
- 核心：**划分**（partition）
- 选基准 → 将小于基准的放左边，大于的放右边 → 递归

```c
// 一趟划分
int Partition(int A[], int low, int high) {
    int pivot = A[low];  // 选第一个元素为基准
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];  // 把小于pivot的移到左边
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];  // 把大于pivot的移到右边
    }
    A[low] = pivot;
    return low;  // 基准最终位置
}
// 时间复杂度: 平均 O(nlogn)，最坏 O(n²)（基本有序时）
// 空间复杂度: O(logn)（递归栈深度）
```

**3. 堆排序：**
- 建堆 $O(n)$，每次调整 $O(\log n)$
- 升序 → 大根堆；降序 → 小根堆

**4. 归并排序：**
- 分治思想，需要 $O(n)$ 额外空间
- 稳定的排序算法

**2.** 快速排序退化的条件和避免方法：
- **退化条件**：每次划分极不平衡（如每次选到最小/最大元素作为基准）

  - **三数取中法**：取首、尾、中间三个元素的中位数作为基准

- 然后通过**多路归并**在外部存储器上进行合并，不需要全部数据同时加载到内存
- 归并过程是**顺序访问**，非常适合磁盘的顺序读写特性

**4.** 快速排序空间复杂度：
- **最少：$O(log n)$** → 每次划分均匀（平衡划分），递归深度 $log₂ n$
- **最多：$O(n)$** → 每次划分极不均匀（退化为冒泡），递归深度 $n$

## 四、算法设计题重点

### 二叉树遍历应用专题

| 问题 | 遍历方式 | 核心思路 |
|------|----------|----------|
| 求叶子结点个数 | 先/后序 | 空返回0，叶子返回1，否则递归求左右+合并 |
| 求二叉树深度 | 后序 | 深度 = max(左深度,右深度) + 1 |
| 交换左右子树 | 先/后序 | 访问时交换lchild和rchild |
| 查找值为x的结点 | 先序 | 根==x则返回，否则递归左右 |
| 判断两树相似 | 先序 | 同时为空→相似；一空一非空→不相似；递归判断左右 |
| 求二叉树权值和 | 任意 | 遍历所有结点，累加权值 |
| 计数单分支结点 | 先/后序 | 判断、计数、递归 |
| 判断是否完全二叉树 | 层序 | 用队列，遇到NULL后不应再有非空结点 |

**关键递归模板：**
```c
// 求叶子结点数
int LeafCount(BiTree T) {
    if (T == NULL) return 0;
    if (T->lchild == NULL && T->rchild == NULL) return 1;
    return LeafCount(T->lchild) + LeafCount(T->rchild);
}

// 求二叉树深度
int Depth(BiTree T) {
    if (T == NULL) return 0;
    int ld = Depth(T->lchild);
    int rd = Depth(T->rchild);
    return (ld > rd ? ld : rd) + 1;
}

// 交换左右子树
void Swap(BiTree T) {
    if (T == NULL) return;
    BiTree temp = T->lchild;
    T->lchild = T->rchild;
    T->rchild = temp;
    Swap(T->lchild);
    Swap(T->rchild);
}
```

### 图的应用专题

| 问题 | 方法 | 核心思路 |
|------|------|----------|
| 判断图的连通性 | DFS/BFS | 从任一顶点出发遍历，访问所有顶点→连通 |
| 求连通分量个数 | DFS/BFS | 计数需要多少次DFS/BFS才能遍历完所有顶点 |
| 判断是否为树 | DFS+边/点关系 | 连通且 e = n-1 |
| 输出简单路径 | DFS+栈 | DFS回溯时记录路径 |

### 三、简答题（每题8分）

**1. （线性表应用）** 将两个递增有序的单链表合并为一个递减有序的单链表。要求利用原结点空间，写出算法思路。

<details>
<summary>📋 答案与解析</summary>

> 🧠 **核心矛盾**：两个递增链表 → 合并结果要递减。用**头插法**——取最小的插到最前面，自然逆序！
>
> **算法思路四步走**：
> 1. 创建新链表 C（带头结点），初始为空
> 2. 同时遍历 A 和 B，每次比较 pa 和 pb 所指结点的值
> 3. **取较小者**，用**头插法**插入 C（较小者先被插到最前面 → 后面更大的排前面 → 递减！）
> 4. 某链表遍历完后，将另一链表剩余元素继续头插到 C
>
> **为什么头插法能实现递减？**
> - 递增序列中最小的先被选中，通过头插放在 C 的最前面 → 它反而是最终链表的最后一个
> - 后续较大值头插进来，依次排在更前面 → C 从前往后是从大到小
>
> ```c
> LinkList MergeDesc(LinkList A, LinkList B) {
>     LinkList C = (LinkList)malloc(sizeof(LNode));
>     C->next = NULL;
>     LNode *pa = A->next, *pb = B->next, *q;
>     while (pa && pb) {
>         if (pa->data <= pb->data) { q = pa; pa = pa->next; }
>         else                      { q = pb; pb = pb->next; }
>         q->next = C->next;   // 头插
>         C->next = q;
>     }
>     while (pa) { q = pa; pa = pa->next; q->next = C->next; C->next = q; }
>     while (pb) { q = pb; pb = pb->next; q->next = C->next; C->next = q; }
>     return C;
> }
> ```
> ⏱ 时间复杂度：$O(m+n)$，空间复杂度：$O(1)$（复用原结点）

</details>

> ⚠️ 14 的探测：14%7=0 被占→1被占→2被占→3被占→4被占→5被占→6空，共探测 7 次！
>
> **Step 3 — ASL 计算：**
>
> $$ASL_{成功} = \frac{1+1+1+1+2+2+7}{7} = \frac{15}{7} \approx 2.14$$

> | 1 | 1→2→3→4→5→6→空 | 6 |
> | 2 | 2→3→4→5→6→空 | 5 |
> | 3 | 3→4→5→6→空 | 4 |
> | 4 | 4→5→6→空 | 3 |

> $$ASL_{不成功} = \frac{7+6+5+4+3+2+1}{7} = \frac{28}{7} = 4$$

</details>

### 四、算法设计题（每题10分）

**1. （二叉树遍历应用）** 设计算法求二叉树中所有单分支结点的个数，并分析时间复杂度。

<details>
<summary>📋 答案与解析</summary>

> 🧠 **单分支结点**：只有左孩子没有右孩子，或只有右孩子没有左孩子的结点。
>
> **递归三要素设计**：
> 1. **终止条件**：空结点 → 返回 0
> 2. **当前结点处理**：判断是否单分支，是则 cnt=1，否则 cnt=0
> 3. **递归合并**：当前计数 + 左子树单分支数 + 右子树单分支数
>
> ```c
> int SingleBranchCount(BiTree T) {
>     if (T == NULL) return 0;          // 递归终止
>     int cnt = 0;
>     if ((T->lchild == NULL && T->rchild != NULL) ||   // 只有右孩子
>         (T->lchild != NULL && T->rchild == NULL))     // 只有左孩子
>         cnt = 1;
>     return cnt + SingleBranchCount(T->lchild) 
>                + SingleBranchCount(T->rchild);
> }
> ```
>
> | 复杂度 | 分析 |
> |--------|------|
> | **时间复杂度** | $O(n)$ — 每个结点访问一次 |
> | **空间复杂度** | $O(h)$ — 递归栈深度。最好（平衡）$O(\log n)$，最坏（单链）$O(n)$ |
>
> > 💡 **得分要点**：①写清递归终止条件 ②写清单分支判断条件 ③必须有复杂度分析

</details>

**2. （图的应用）** 设计算法判断无向图中是否存在一条从顶点 u 到顶点 v 的简单路径，并分析时间复杂度。

<details>
<summary>📋 答案与解析</summary>

> 🧠 **简单路径**：路径上的顶点不重复出现。
>
> **算法思路**：采用**深度优先搜索（DFS）** + visited 标记。
> - 从起点 u 出发，沿未访问的邻接点深入
> - 用 `visited[]` 数组标记已访问顶点（防止回路）
> - 当 DFS 到达终点 v 时，说明存在路径
>
> ```c
> int visited[MAXV];
> 
> int DFS_Path(ALGraph G, int cur, int target) {
>     if (cur == target) return 1;      // 到达目标！
>     visited[cur] = 1;                  // 标记已访问
>     EdgeNode *p = G.vertices[cur].firstEdge;
>     while (p != NULL) {
>         if (!visited[p->adjvex])       // 邻接点未访问
>             if (DFS_Path(G, p->adjvex, target))
>                 return 1;              // 找到，逐层返回
>         p = p->next;
>     }
>     return 0;                          // 此路不通
> }
> 
> int HasSimplePath(ALGraph G, int u, int v) {
>     for (int i = 0; i < G.vertexNum; i++) visited[i] = 0;
>     return DFS_Path(G, u, v);
> }
> ```
>
> | 复杂度 | 分析 |
> |--------|------|
> | **时间复杂度** | 邻接表：$O(n+e)$；邻接矩阵：$O(n^2)$ |
> | **空间复杂度** | $O(n)$ — visited 数组 + 递归栈 |
>
> > 💡 **得分要点**：①说明使用 DFS 的理由 ②有 visited 标记防止回路 ③代码有注释 ④必须写复杂度分析

</details>
