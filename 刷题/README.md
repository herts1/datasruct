## 使用约定

- 每题一个文件夹：`题目.md`（原文归档）、`题解.md`（思路+代码+易错点）、参考代码 `.java`
- 易错点会汇总到题解中，方便 Ctrl+F 检索

## 如何验证代码

进入题目文件夹后运行（需本机已装 JDK）：

```powershell
cd BD202402-跑步
powershell -ExecutionPolicy Bypass -File verify.ps1
```

`verify.ps1` 会重新编译、跑官方样例、并和独立实现交叉对比，全部 PASS 才输出 `VERIFY PASS`。

## 编译/交叉验证 C++ 版

```powershell
cd BD202402-跑步
g++ -O2 -static -std=c++17 -o BD202402.exe BD202402.cpp   # 编译
powershell -ExecutionPolicy Bypass -File crosscheck.ps1    # Java vs C++ 逐 n 对比
```
