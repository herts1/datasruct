# LC0006 Z字形变换 题解

- **难度**：中等
- **核心考点**：按行模拟（方向变量）、周期规律
- **复杂度**：O(n) 时间 / O(n) 空间
- **验证**：3 个官方样例 + 300 个随机串与独立网格模拟对照全部一致；n=1000 时 C/C++ 均 0.04s

---

## 一、核心算法：按行模拟（主解）

### 关键观察

Z 字形的**写入路径**非常有规律：从第 0 行出发向下走，走到最后一行，掉头向上，走回第 0 行，再掉头向下……如此往复，直到把所有字符放完。

### 实现思路

用两个变量模拟这条路径：

- `row`：当前字符应该放在第几行
- `dir`：当前移动方向（+1 向下，−1 向上）

每个字符直接追加到 `rows[row]` 的末尾（**不关心列号**——因为最后输出是按行拼接，列位置无关紧要，这是比"建网格"更聪明的简化）。走到边界就转向：

```c
for (int i = 0; i < n; i++) {
    rows[row][len[row]++] = s[i];   // 放进当前行
    row += dir;                      // 移动
    if (row == numRows - 1 || row == 0) dir = -dir;  // 撞边转向
}
```

最后把每行的字符串按顺序拼起来就是答案。

### 为什么不用真的建网格？

Z 字形里字符有"列"的概念，但输出只关心"行"。按行模拟直接跳过列坐标，**省掉网格数组，还避免处理空格占位**——这是这类题的常见简化技巧。

### 复杂度

- 时间 O(n)：每个字符只处理一次
- 空间 O(n)：n 个字符分存到各行的缓冲里

## 二、方法 2：周期规律（进阶，可做 O(1) 额外空间）

Z 字形是严格周期性的，一个完整周期（从第 0 行下去再回到第 0 行）包含的字符数：

```
T = 2·numRows − 2
```

原串里下标相差 T 的字符都在**同一行的同一列**：

- **第 0 行**和**最后一行**：每周期只出现 1 次，间隔 T
- **中间行 i**：每周期出现 2 次，先走 T−2i 步，再走 2i 步（交替）

用这个规律可以直接按"行"取字符，**不建任何行缓冲**：

```c
for (int row = 0; row < numRows; row++) {
    for (int i = row; i < n; i += T) {
        输出 s[i];
        int j = i + T - 2*row;          // 中间行的第二个字符
        if (row > 0 && row < numRows-1 && j < n) 输出 s[j];
    }
}
```

同样 O(n) 时间，但额外空间降到 O(1)（只存答案）。理解周期公式，能加深对 Z 字形结构的直觉。

## 三、两种方法对比

| 方法 | 时间 | 空间 | 代码量 | 直观程度 |
|------|------|------|--------|----------|
| 按行模拟（推荐） | O(n) | O(n) | 短 | ★★★ 最直观 |
| 周期规律 | O(n) | O(1) | 中 | ★★ 需要推导 |

n ≤ 1000 时两种都随便过；**面试首选按行模拟**（好写、好讲），周期规律作为加分点提一嘴。

## 六、易错点清单

| 坑 | 正确姿势 |
|----|----------|
| numRows=1 忘特判 | 1 行时 dir 会反复翻转，结果错乱；`numRows==1` 直接返回原串 |
| numRows >= n 忘特判 | 行数比字符多时 Z 字形成了一列，结果也是原串 |
| 转向时机写错 | 顺序是"放字符 → 移动 → 判边界转向"，不是"先转向再移动" |
| 以为必须建二维网格 | 输出只按行读，按行模拟即可，不用管列 |
| 网格法里空位处理 | 用 '\0' 占位、按非空收集，注意别把 '\0' 当字符输出 |
