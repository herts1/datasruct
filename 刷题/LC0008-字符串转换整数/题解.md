# LC0008 字符串转换整数 myAtoi 题解

- **难度**：中等
- **核心考点**：字符串解析四阶段、**32 位溢出防护**（乘法前判断）
- **复杂度**：O(n) 时间 / O(1) 空间
- **验证**：5 官方样例 + 14 边界用例 + 300 随机 vs 独立暴力对照全部一致（C/C++ 双版）

---

## 一、解析流程：四个阶段

```
"   -042abc"  →  ①跳空格 ②读符号 ③读数字 ④截断
     ↑↑↑        "042" 前导零忽略，读到 'a' 停止 → 结果 -42
```

1. **跳空格**：`while (i < n && s[i] == ' ') i++;`
2. **读符号**：只允许一个 `+`/`-`，没有就默认正
3. **读数字**：`0-9` 连续读取，遇到非数字立即停止（**中途出现符号、字母、小数点都算停止**）
4. **截断**：超出 [INT_MIN, INT_MAX] 就 clamp 到边界

## 二、核心考点：防溢出（本题的灵魂）

### 错误写法 1：先转 long long 再 clamp ❌

```c
long long v = ...;   // s 最长 200 位数字，long long 只有 ~19 位，照样溢出
```

### 错误写法 2：乘完再判断 ❌

```c
ans = ans * 10 + d;         // 此时 ans*10 已经溢出（未定义行为！）
if (ans > INT_MAX) ...      // 判断的是溢出后的垃圾值
```

### 正确写法：乘法前判断 ✅

```c
if (ans > (INT_MAX - d) / 10) {       // ans*10 + d 必超 INT_MAX
    return sign == 1 ? INT_MAX : INT_MIN;
}
ans = ans * 10 + d;
```

**数学原理**（恒等变形，避免了乘法）：

$$ans \cdot 10 + d > \text{INT\_MAX} \iff ans > \frac{\text{INT\_MAX} - d}{10}$$

右边是**先减后除**，永远在安全范围内，然后才放心做 `ans*10 + d`。

### 负数边界为什么特别容易错

INT_MIN = −2147483648，它的**绝对值比 INT_MAX 大 1**。所以：
- 用"正数累加 + 符号"统一处理（绝对值最多到 2147483648）
- 判断 `ans > (INT_MAX - d)/10` 时，若超界：`sign==1 → INT_MAX`，`sign==-1 → INT_MIN`（一箭双雕，-2147483648 也能正确返回）

## 五、易错点清单

| 坑 | 正确姿势 |
|----|----------|
| 用 scanf("%s") 读输入 | 输入含空格，必须 fgets/getline 读整行 |
| ans*10+d 之后才判断溢出 | 乘法前用 `(INT_MAX-d)/10` 判断（UB 提前拦截） |
| 忘记 INT_MIN 绝对值比 INT_MAX 大 1 | 统一正数累加 + 符号，超界按 sign 返回不同边界 |
| 数字中途遇到符号就停 | "0-1" → 0；"-123abc" → -123；".5" → 0（'.' 不是数字）|
| 前导零没跳过 | 累加自然忽略前导零（0*10+n 不影响），不用特殊处理 |
| 只允许一个符号 | "+-5" 读 '+' 后遇 '-' 不是数字 → 0 |
