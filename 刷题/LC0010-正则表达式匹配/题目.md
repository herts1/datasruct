# LC0010 正则表达式匹配（LeetCode 10）

## 题目描述

给你一个字符串 s 和一个字符规律 p，请你来实现一个支持 '.' 和 '*' 的正则表达式匹配。

- '.' 匹配任意单个字符
- '*' 匹配零个或多个**前面的那一个元素**

返回一个布尔值，表示匹配是否覆盖整个输入字符串（而非部分）。

## 示例

| s | p | 输出 | 说明 |
|---|----|------|------|
| "aa" | "a" | false | "a" 无法匹配 "aa" 整个字符串 |
| "aa" | "a*" | true | '*' 代表前面的元素 'a' 重复零次或多次 |
| "ab" | ".*" | true | ".*" 表示零个或多个任意字符 |

## 提示

- 1 ≤ s.length ≤ 20
- 1 ≤ p.length ≤ 20
- s 只包含从 a-z 的小写字母
- p 只包含从 a-z 的小写字母，以及字符 '.' 和 '*'
- 保证每次出现字符 '*' 时，前面都匹配到有效的字符

## 核心考点

- 动态规划（二维 DP）
- '*' 的两种语义：匹配零个 / 匹配一个或多个
- 覆盖整个串（不是子串匹配）
