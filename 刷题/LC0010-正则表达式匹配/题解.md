# LC0010 正则表达式匹配 题解

- **难度**：困难
- **核心考点**：二维 DP、'*' 的两种语义（零个 / 一个或多个）
- **复杂度**：O(n·m) 时间 / O(n·m) 空间（n, m ≤ 20，可滚动到 O(m)）
- **验证**：17 个固定用例（含官方 3 例 + 经典反例）+ 300 随机 vs 独立递归暴力全部一致（C/C++ 双版）

---

## 一、状态定义

```
dp[i][j] = s 的前 i 个字符（s[0..i-1]）能否被 p 的前 j 个字符（p[0..j-1]）匹配
```

| 位置 | 含义 |
|------|------|
| dp[0][0] = true | 空串匹配空模式 |
| dp[0][j] | 空串 vs 模式：只有 `x*` 组合能匹配空（`x` 取零个），如 "a*b*c*" |
| dp[i][0] (i>0) = false | 非空串匹配空模式，不可能 |

## 二、状态转移（本题灵魂）

设当前处理到 dp[i][j]，看 p 的**最后一个字符** p[j-1]：

### 情况 1：p[j-1] == '*'（x* 组合，x = p[j-2]）

有两种选择，任一成立即可：

1. **匹配零个**：把 `x*` 整个丢弃 → `dp[i][j] = dp[i][j-2]`
2. **匹配一个或多个**：前提 `x` 能匹配 `s[i-1]`（`x == '.'` 或 `x == s[i-1]`），
   然后"再多匹配一个 x"——即 s 的前 i-1 个已经匹配好 → `dp[i][j] |= dp[i-1][j]`

```c
dp[i][j] = dp[i][j-2];                          // 零个
if (matchChar(p[j-2], s[i-1]))
    dp[i][j] |= dp[i-1][j];                     // 一个或多个
```

### 情况 2：普通字符或 '.'

直接看最后一个字符能否对上，能对上就看前面：

```c
dp[i][j] = matchChar(p[j-1], s[i-1]) && dp[i-1][j-1];
```

## 三、为什么 dp[i-1][j] 表示"一个或多个"

直观理解：`a*` 匹配 `"aaa"` 时——
- 最后一个 'a' 由 `a*` 的"再来一个"吃掉：dp[3][2] 依赖 dp[2][2]
- dp[2][2] 又是 dp[1][2]（再吃一个）…
- 最后 dp[0][2] = true（`a*` 匹配零个 a，即空串）

这一串递推把"重复任意次"压进了 `dp[i-1][j]` 这一个转移里，这就是 DP 化递归的妙处。

## 四、边界初始化

```c
dp[0][0] = true;
for (j = 2; j <= m; j++)
    if (p[j-1] == '*') dp[0][j] = dp[0][j-2];   // x* 匹配空串
```

## 七、易错点清单

| 坑 | 正确姿势 |
|----|----------|
| 把 '*' 当成独立通配符 | '*' 必须配合**前一个字符** x 使用（x*），本身不能匹配 |
| 忘了"零个"分支 | `x*` 匹配零个 = 整个丢弃，`dp[i][j-2]` 这半边不能少 |
| '.' 只匹配一个字符 | '.' 相当于"任意单一字符"，不是任意串 |
| 匹配整个串 vs 子串 | dp 全串覆盖；子串匹配是另一题 |
| 初始化只写 dp[0][0] | 还要处理 dp[0][j]（x* 匹配空串） |
| 用 i 直接索引字符串 | dp 的 i 是"前 i 个"，对应 s[i-1]，差一错误高发 |

## 八、变式练习

1. **变式 1**：LeetCode 44 通配符匹配——'?' 匹配任意单字符，'*' 匹配任意串（不含前驱），转移怎么简化？（提示：* 不再绑定前驱，`dp[i][j] = dp[i-1][j] || dp[i][j-1]`）
2. **变式 2**：把 DP 空间压到 O(m)（滚动数组）
3. **变式 3**：打印一种可行的匹配方案（回溯记录路径）
4. **变式 4**：正则引擎的 NFA 视角：把模式看成状态机，DP 等价于 NFA 模拟
