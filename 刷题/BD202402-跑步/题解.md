# BD202402 跑步 题解

- **难度**：星耀 ⭐⭐⭐（数学题）
- **考点**：lcm（最小公倍数）、求和化简、乘法逆元、线性筛（欧拉筛）、线性求逆元
- **复杂度**：O(n) 时间 / O(n) 内存（n ≤ 10^7 可行）
- **验证**：本机实测通过两个官方样例；n=1..60 与 BigInteger 精确版完全一致；n=10^7 运行 0.29 秒

---

## 一、第一步：确定总时间 T

第 i 名同学跑一圈要 i 分钟，所以 ta 回到起点的时刻是 i 的倍数：i, 2i, 3i, …

要求 **所有人同时** 回到起点才停，所以总时间 T 必须是每个 i (1 ≤ i ≤ n) 的公共倍数，最小就是：

$$T = \text{lcm}(1, 2, \dots, n)$$

> **lcm 是什么**：最小公倍数（Least Common Multiple）。比如 lcm(2,3)=6，因为 6 既是 2 的倍数又是 3 的倍数，且是最小的。  
> 例：n=3 时 T = lcm(1,2,3) = 6，与题目样例"总共跑步时长为 6 分钟"一致 ✓

## 二、第二步：两人多久打一次招呼

同学 i 的速度是 1/i 圈/分钟，同学 j 的速度是 1/j 圈/分钟（i < j）。

两人位置相同 ⟺ 路程差是 **整圈数**（你追我赶，快的人套圈套到慢的人）。

t 分钟后路程差 = (1/i − 1/j)·t = (j−i)/(ij)·t，要求它是整数：

$$t \cdot \frac{j-i}{ij} \in \mathbb{Z} \iff t = k \cdot \frac{ij}{j-i} \quad (k = 1, 2, \dots)$$

所以相遇周期 $t_0 = \frac{ij}{j-i}$（可能是分数，没关系）。在 (0, T] 内的次数：

$$\frac{T}{t_0} = \frac{T(j-i)}{ij} = \frac{T}{i} - \frac{T}{j}$$

**验证**（n=3）：i=1, j=3 → 次数 = 6/1 − 6/3 = 4（时刻 1.5, 3, 4.5, 6 ✓ 与样例吻合）

## 三、第三步：把总次数化成漂亮的和式

$$\text{Ans} = \sum_{1 \le i < j \le n} \left(\frac{T}{i} - \frac{T}{j}\right)$$

- T/i 作为"被减数"出现 (n−i) 次（i 可以和所有 j > i 配对）
- T/j 作为"减数"出现 (j−1) 次（j 可以和所有 i < j 配对）

$$\text{Ans} = \sum_{i=1}^{n} (n-i)\frac{T}{i} - \sum_{j=1}^{n} (j-1)\frac{T}{j} = \sum_{i=1}^{n} (n+1-2i)\frac{T}{i}$$

再拆开：$\sum (n+1)\frac{T}{i} - \sum 2i\cdot\frac{T}{i} = (n+1)\sum\frac{T}{i} - 2nT$（因为 $i \cdot \frac{T}{i} = T$）

**最终公式**：

$$\boxed{\text{Ans} = (n+1)\sum_{i=1}^{n}\frac{T}{i} \;-\; 2nT}$$

## 四、第四步：模 998244353 下怎么算（核心考点）

问题：T 是天文数字（n=10^7 时 T 有上百万位），T/i 根本存不下，必须全程取模。但 T/i 是 **整数**（i | T 由 lcm 定义保证），怎么取模？

**关键观察**：模素数 p 下每个非零数都有逆元。记 i⁻¹ 为 i 的模逆元（i·i⁻¹ ≡ 1 mod p）。因为 i | T，令 T = i·q（q 是整数）：

$$T \cdot i^{-1} \equiv (i\cdot q)\cdot i^{-1} \equiv q = \frac{T}{i} \pmod p$$

**所以 $\sum \frac{T}{i} \equiv T \cdot \sum i^{-1} \pmod p$**，把"除"变成"乘逆元"。

> ⚠️ **易错点**：这里能用逆元的**前提是 i | T**（整除）！如果 i 不整除 T，T·i⁻¹ 和 T/i 模 p 不相等（差一个余数·逆元）。初学者常见的坑是看见 1/i 就直接用逆元——只有分子被分母整除时才安全。

**剩下的实现问题**：
1. T mod p = Π p^{e_p} mod p，其中 e_p = ⌊log_p n⌋（对每个素数 p ≤ n，取"≤ n 的最大幂"）
2. Σ i⁻¹ 用 **线性递推** O(n) 求所有逆元：
   $$inv[i] = p - \lfloor p/i \rfloor \cdot inv[p \bmod i] \bmod p$$
   （因为 n ≤ 10^7 < p = 998244353，p mod i ∈ [1, i−1]，保证已算出）
3. 素数用欧拉筛 O(n) 得到

## 七、易错点清单

| 坑 | 正确姿势 |
|----|----------|
| 以为相遇时刻都是整数 | 时刻可以是分数（如 3/2 分钟），只要路程差是整圈 |
| 忘记 0 时刻不打招呼 | 相遇次数 = T/t₀（开区间 (0,T]），不是 T/t₀ + 1 |
| 直接用 1/i 的逆元算 | 前提 i \| T 才成立；本题 T=lcm 恰好保证，但别的题不一定 |
| 公式里 2nT 忘记取模 | 所有中间量都要 mod p，且转 long 防溢出 |
| 线性逆元公式记错 | inv[i] = p − (p/i)·inv[p%i] mod p，方向别反 |
| 欧拉筛不写 break | 少了 `if (i % primes[j] == 0) break;` 每个合数会被筛多次，退化成 O(n log n) |
