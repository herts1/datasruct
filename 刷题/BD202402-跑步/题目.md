# BD202402 跑步（百度之星 2024）

## 题目描述

小度与他的同学们十分热爱运动，现有包括小度在内的 n 名同学想要去某圆形操场跑步。

已知第 i 名同学跑一圈的时间为 i 分钟一圈。

小度他们规定，他们 n 名同学同时从起点出发，一直跑到 n 名同学同时到达起点时停止。

对于任意两名同学，如果在某一时刻的位置相同，那么他们便会打 1 次招呼。
如果同时有多名同学在某一时刻都在同一位置，那么每一对同学都会相互之间打招呼。

注：最后一起到终点的时候，也会打一次招呼。

现在小度想要问你，直到跑步结束所有同学相互之间一共会打多少次招呼。
由于答案过大，所以希望你将答案对 **998244353** 取模。

## 输入格式

1 行 1 个整数 n 表示参加跑步的同学人数。

数据保证 1 ≤ n ≤ 10^7。

## 输出格式

1 行 1 个整数代表答案。

## 样例

### 样例 1

输入：

```
3
```

输出：

```
8
```

### 样例 2

输入：

```
10000000
```

输出：

```
424046265
```

## 样例 1 解释

3 个人总共跑步时长为 6 分钟，其中 3 个人共打招呼了 8 次。

按照时间顺序分别为：

- 第 3/2 分钟，第 1 名同学与第 3 名同学打了一次招呼；
- 第 2 分钟，第 1 名同学与第 2 名同学打了一次招呼；
- 第 3 分钟，第 1 名同学与第 3 名同学打了一次招呼；
- 第 4 分钟，第 1 名同学与第 2 名同学打了一次招呼；
- 第 9/2 分钟，第 1 名同学与第 3 名同学打了一次招呼；
- 第 6 分钟，第 1 名同学与第 2 名同学打了一次招呼；
- 第 6 分钟，第 1 名同学与第 3 名同学打了一次招呼；
- 第 6 分钟，第 2 名同学与第 3 名同学打了一次招呼。

## 数据范围

- 1 ≤ n ≤ 10^7
