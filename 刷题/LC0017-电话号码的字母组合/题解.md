# LC0017 电话号码的字母组合 题解

- **难度**：中等
- **核心考点**：回溯（DFS）、映射表
- **复杂度**：O(3^m × 4^n) 时间（m 个 3 字母数字、n 个 4 字母数字）× 结果长度；空间 O(len + 结果数)
- **验证**：3 官方样例 + 200 随机组（回溯 C / 回溯 C++ / 迭代 BFS 三实现互相对比 + 性质检查）全部一致

---

## 一、问题模型

```
digits = "23"
    ↓        第 1 位         第 2 位
   '2' →  a/b/c  ──→  各自接上 '3' 的 d/e/f
   结果 = ad, ae, af, bd, be, bf, cd, ce, cf   （3 × 3 = 9 个）
```

这是一个**多叉树的枚举**：每一层是一个数字，每个分支是该数字的一个映射字母。总叶子数 = 各数字字母数的**乘积**（本题 ≤ 4⁴ = 256）。

## 二、回溯（DFS）—— 主解

```c
void dfs(digits, pos, buf, res, cnt) {
    if (pos == len) {          // 所有位都选好了 → 记下一个结果
        res[cnt++] = strdup(buf);
        return;
    }
    for (每个 letters = table[digits[pos]] 中的字符 c) {
        buf[pos] = c;          // 第 pos 位选 c
        dfs(digits, pos + 1, ...);   // 递归下一位
    }
}
```

**状态**：
- `pos`：当前处理到第几位（树的层数）
- `buf`：已经选好的前缀（正在构造的组合）

**终止条件**：`pos == len` 时前缀就是完整组合，写入结果。

## 三、迭代（BFS）—— 对照思路

结果列表初始为 `[""]`，每处理一个数字，把当前每个前缀分别拼接该数字的所有映射字母，得到新列表：

```
[""] → 处理 '2' → ["a","b","c"] → 处理 '3' → ["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

本质与回溯等价（都是笛卡尔积枚举），但用显式的列表迭代，不依赖递归。本题提供了 `bfs.c` 作为独立对照实现。

## 四、复杂度

- 结果总数 = Π(每个数字的字母数)，上界 4^len
- 每个结果构造/拷贝 O(len) → 总时间 O(结果数 × len)
- 空间：回溯 O(len)（递归深度）+ 结果存储 O(结果数 × len)

## 七、易错点清单

| 坑 | 正确姿势 |
|----|----------|
| 映射表写错 | 7 是 pqrs（4 个）、9 是 wxyz（4 个），不是 3 个！|
| 数组越界 | `digits[pos] - '0'` 索引 table，digits 只含 '2'..'9' |
| 忘了字符串终止符 | C 版 `buf[n] = '\0'` 必须手动加 |
| 空串 digits | C 返回 NULL + returnSize=0；C++ 返回空 vector |
| 结果数预分配算错 | total = 各数字字母数乘积（先算再 malloc）|
| 递归忘回溯 | 本解法用 `buf[pos] = c` 原地覆盖，天然免回溯；若用 push_back 则要 pop_back |
