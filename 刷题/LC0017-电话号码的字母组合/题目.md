# LC0017 电话号码的字母组合（LeetCode 17）

## 题目描述

给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。答案可以按任意顺序返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

```
2: abc    3: def    4: ghi
5: jkl    6: mno    7: pqrs
8: tuv    9: wxyz
```

## 示例

### 示例 1

输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]

### 示例 2

输入：digits = "2"
输出：["a","b","c"]

## 提示

- 1 ≤ digits.length ≤ 4
- digits[i] 是范围 ['2', '9'] 的一个数字

## 核心考点

- 回溯（DFS）：树形枚举
- 映射表
- 组合数 = 各数字字母数的乘积（最多 4⁴ = 256 个）
