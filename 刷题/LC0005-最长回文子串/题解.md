# LC0005 最长回文子串 题解

- **难度**：中等
- **核心考点**：回文串对称性、中心扩展法
- **推荐复杂度**：O(n²) 时间 / O(1) 空间（n ≤ 1000 足够）
- **验证**：两个官方样例 + 200 个随机串与 O(n³) 暴力对照全部一致；n=1000 全 a 最坏情况 C 0.09s / C++ 0.27s

---

## 一、核心算法：中心扩展法（主解）

### 关键观察

**回文串关于中心对称**。所以只要确定"中心"，就能向两边逐字符扩展，直到左右不相等，从而得到以该中心为轴的最长回文。

### 中心有 2n-1 个

| 类型 | 示例 | 中心位置 |
|------|------|----------|
| 奇数长度回文 | "aba" | 单个字符 'b'（下标 i） |
| 偶数长度回文 | "bb" | 两个字符之间（下标 i 与 i+1 之间） |

### 实现要点

```c
// 以 (l, r) 为中心向外扩展，返回最大回文长度
int expand(char* s, int n, int l, int r) {
    while (l >= 0 && r < n && s[l] == s[r]) { l--; r++; }
    return r - l - 1;          // 退出时已多走一步
}

for (int i = 0; i < n; i++) {
    int len1 = expand(s, n, i, i);      // 奇数中心
    int len2 = expand(s, n, i, i + 1);  // 偶数中心
    int len = max(len1, len2);
    if (len > maxLen) {
        maxLen = len;
        start = i - (len - 1) / 2;      // 反推左端点（奇偶通用公式）
    }
}
```

**为什么 `start = i - (len-1)/2` 奇偶通用**：
- 奇数 len=2k+1：左端点 = i − k = i − (len−1)/2 ✓
- 偶数 len=2k：左端点 = i−k+1，而 (len−1)/2 = (2k−1)/2 = k−1（整除），i − (len−1)/2 = i−k+1 ✓

### 复杂度

- 时间 O(n²)：2n−1 个中心，每个最坏向外扩 O(n)
- 空间 O(1)：只存 start 和 maxLen

## 二、四种解法对比

| 方法 | 时间 | 空间 | 思路 |
|------|------|------|------|
| 暴力枚举 | O(n³) | O(1) | 枚举所有子串 [i,j]，逐个判断是否回文 |
| 区间 DP | O(n²) | O(n²) | dp[i][j] = s[i..j] 是否回文，dp[i][j] = (s[i]==s[j] && dp[i+1][j-1]) |
| **中心扩展（推荐）** | **O(n²)** | **O(1)** | 枚举 2n−1 个中心向外扩 |
| Manacher | O(n) | O(n) | 利用已算出的回文信息镜像复制，n 很大时才需要 |

n ≤ 1000 时 O(n²) 绰绰有余，中心扩展最优（代码短、空间省）；n ≥ 10⁵ 才考虑 Manacher。

## 五、易错点清单

| 坑 | 正确姿势 |
|----|----------|
| 只考虑奇数长度回文 | 必须同时枚举偶数中心 (i, i+1)，漏了 "bb" 这类会错 |
| expand 返回长度算错 | 退出时 l、r 已越界，长度 = r−l−1，不是 r−l+1 |
| 多个等长答案时输出不一致 | 题目允许任一，验证时比长度而非具体串 |
| start 计算只写奇数公式 | 用统一公式 `i − (len−1)/2`（整除） |
| n=1 忘兜底 | 初始化 maxLen=1 即可覆盖单字符 |

## 六、变式练习

1. **变式 1**：输出所有最长回文子串（不只一个）
2. **变式 2**：判断 s 能否通过删去最少字符变成回文（LPS 与 LCS 的关系）
3. **变式 3**：把中心扩展改成区间 DP 写法，比较两种实现
4. **变式 4**：s 长度改成 10⁵，用 Manacher 实现 O(n)
