# LC0015 三数之和 题解

- **难度**：中等
- **核心考点**：排序 + 双指针、三处去重、剪枝
- **复杂度**：O(n²) 时间 / O(1) 额外空间（排序 O(n log n)）
- **验证**：7 个固定用例（含官方 3 例）+ 200 随机 vs O(n³) 暴力全部一致（C/C++ 双版）；n=3000 时 C 0.3s / C++ 0.17s

---

## 一、核心算法：排序 + 双指针

### 第一步：排序

排序让三件事变简单：
1. 重复值相邻 → 可以去重
2. 三元组内自然有序（a ≤ b ≤ c）→ 答案统一形态
3. 有序数组上可以用双指针做"两数之和"

### 第二步：固定第一个数，双指针找另外两个

```
for i in 0..n-3:
    目标 = -nums[i]
    在 [i+1, n-1] 里用双指针 l、r 找两数和 = 目标
```

双指针夹逼（有序数组）：

```
sum = nums[l] + nums[r]
sum < 目标 → l++（和太小，往右找更大的）
sum > 目标 → r--（和太大，往左找更小的）
sum == 目标 → 记录三元组，跳过重复，l++ r--
```

## 二、三处去重（本题最容易被扣分的点）

| 去重位置 | 代码 | 作用 |
|----------|------|------|
| ① 外层 i | `if (i>0 && nums[i]==nums[i-1]) continue;` | 同一首元素只处理一次 |
| ② 内层左 | `while (l<r && nums[l]==nums[l+1]) l++;` | 找到一组后跳过重复的左值 |
| ③ 内层右 | `while (l<r && nums[r]==nums[r-1]) r--;` | 找到一组后跳过重复的右值 |

**关键时机**：去重是在**找到一组之后**跳过（②③），而不是移动指针之前——否则会漏解。
外层去重①用 `nums[i]==nums[i-1]`（和前一个比），不是 `nums[i]==nums[i+1]`（和后一个比）——后者会漏掉 `[-1,-1,2]` 这类合法解。

## 三、剪枝

```c
if (nums[i] > 0) break;   // 最小数 > 0，三数和必 > 0，直接结束
```

（进阶剪枝：`nums[i]+nums[i+1]+nums[i+2] > 0` 也可 break；`nums[i]+nums[n-1]+nums[n-2] < 0` 可 continue）

## 四、复杂度

- 排序 O(n log n)，主循环 O(n²)（外层 n × 内层双指针 n）
- 额外空间 O(1)（不计算答案存储）

## 七、易错点清单

| 坑 | 正确姿势 |
|----|----------|
| 忘了排序 | 双指针的前提是有序，不排序无法夹逼 |
| 外层去重写成 `nums[i]==nums[i+1]` | 会漏解 `[-1,-1,2]`；必须和前一个比 |
| 内层去重放在移动指针前 | 会漏解；应在**找到一组后**跳过重复值 |
| 只去重 l 不去重 r | 两个方向都要跳，否则重复三元组 |
| 剪枝条件写错 | `nums[i] > 0` 才 break（排序后），不是 `>= 0` |
| 输出顺序 | 三元组内部有序（排序保证），整体顺序无关（验证时集合比较） |
