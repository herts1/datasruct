# LC0015 三数之和（LeetCode 15）

## 题目描述

给你一个整数数组 nums，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k，同时还满足 nums[i] + nums[j] + nums[k] == 0。

请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

## 示例

### 示例 1

输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]

不同的三元组是 [-1,0,1] 和 [-1,-1,2]（注意输出的顺序和三元组的顺序并不重要）。

### 示例 2

输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0。

### 示例 3

输入：nums = [0,0,0]
输出：[[0,0,0]]

## 提示

- 3 ≤ nums.length ≤ 3000
- -10⁵ ≤ nums[i] ≤ 10⁵

## 核心考点

- 排序 + 双指针（固定一个数，剩两个数用双指针夹逼）
- 三处去重（外层 i、内层 l、内层 r）
- 剪枝优化
