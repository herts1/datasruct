# BD202404 110串 题解

- **难度**：星耀 ⭐⭐⭐（计数 DP）
- **考点**：动态规划（计数 DP）、滚动数组
- **复杂度**：O(n·k·8) ≈ 2×10⁸ 时间 / O(4·k) 内存（n, k ≤ 5000）
- **验证**：本机实测通过官方样例；n=1..10 全枚举 + n=11..14 随机共 2 万+ 组与暴力对照一致；Java vs C++ 随机 100 组一致；n=k=5000 耗时 Java 0.65s / C++ 0.49s

---

## 一、先把题意翻译成数学模型

修改不超过 k 个数字 = 最终串和原串最多有 k 个位置不同 = **汉明距离 ≤ k**。

所以问题等价于：

> 统计所有长度为 n 的 01 串 t，满足：
> ① t 不含子串 "110"
> ② t 与给定串 s 的汉明距离 ≤ k
> 求个数 mod 998244353。

（给定原串后，每个合法的 t 唯一对应一种修改方式，所以方案数 = 合法 t 的个数。）

## 二、为什么用 DP：抓住"只看最后两位"

判断一个串是否含 "110"，扫描时只需要关心**刚刚填过的两位**：

- 填第 i 位时，只有 `(a[i-2], a[i-1], a[i]) == (1,1,0)` 才非法
- 换句话说：只要**最后两位不是 "11"**，下一位填 0 或 1 都安全；
  如果**最后两位是 "11"**，下一位必须填 1（填 0 就成 110 了）

这就是"**无后效性**"：前面的历史对未来的影响，全部浓缩在"最后两位"这一个信息里——这正是 DP 能用起来的标志。

## 三、状态设计与转移

**状态**：`dp[state][cnt]` = 已构造前 i 位、最后两位为 state、总共改了 cnt 个位置的方案数。
其中 `state = (last2 << 1) | last1`，共 4 种：

| state | 二进制 | 含义（最后两位） |
|-------|--------|------------------|
| 0 | 00 | 最后两位是 00 |
| 1 | 01 | 最后两位是 01 |
| 2 | 10 | 最后两位是 10 |
| 3 | 11 | 最后两位是 11 |

**转移**：枚举下一位填 b ∈ {0,1}：

```
非法：last2==1 且 last1==1 且 b==0（形成 110），跳过
合法：新状态 nstate = (last1 << 1) | b
     新修改次数 ncnt = cnt + (b != s[i] ? 1 : 0)
     dp'[nstate][ncnt] += dp[state][cnt]
```

**边界**：第 1 位没有前两位，用一个**虚拟前位 0** 初始化——因为 110 需要 last2=1，虚拟成 0 永远不会误判；而长度 2 时本来也不可能出现 110。这样实现最省事（避免单独讨论 n=1、2）。

**答案**：处理完 n 位后，Σ 所有 state、cnt ≤ k 的 dp 值。

## 四、复杂度与优化

- 状态数 4 × (k+1)，转移 2 种 → 每层 O(8k)，共 n 层 → **O(8nk)**
- 空间：只依赖上一层 → **滚动数组**，O(4k)
- 小优化：`if (v == 0) continue;` 跳过空状态；加法后立即取模防溢出

## 七、易错点清单

| 坑 | 正确姿势 |
|----|----------|
| 把"方案数"理解成修改次数 | 方案数 = 合法最终串的个数（汉明距离 ≤ k）|
| 以为要记录连续 3 位 | 只需最后两位：110 的判定在填新位时完成 |
| 忽略 k > n | 最多改 n 个位置，先 `k = min(k, n)` |
| 第 1 位单独讨论 | 用虚拟前位 0 统一处理，注意虚拟位不能是 1（会误判 110）|
| 用 int 累加不取模 | 加一次就超 2×10⁹ 会溢出，加完立即取模或转 long |
| 忘了"11 后必须跟 1" | 状态 3（11）时 b=0 直接跳过，这是唯一非法转移 |

## 八、变式练习

1. **变式 1**：把禁子串从 "110" 改成 "101"，转移条件怎么改？（提示：非法组合变成 (1,0,1)，即 last2=1,last1=0 时 b=1 跳过）
2. **变式 2**：改成"恰好修改 k 次"（不是不超过），答案怎么取？（提示：只统计 cnt == k 的层）
3. **变式 3**：禁子串换成任意长度 m 的模式，状态要扩大到几位？（提示：最后 m-1 位，状态数 2^(m-1)）
